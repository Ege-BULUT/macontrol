See where your disk space went, and get it back safely.

A native Mac app that maps your disk and cleans it up. Everything it removes goes to the Trash first, so you can always put it back.

One window to see it and free it.

Most disk tools either show you where the space went or offer to clean it up. macontrol does both, on one scan engine and one safety layer.

Find what takes up the space

A sunburst or a treemap of your home folder, the startup disk or any folder, sized by what each item takes up on disk.

  • Proportional to bytes. Items too small to draw are grouped into one “smaller items” entry that lists them, so nothing silently disappears.
  • Honest numbers. Hard links count once, and a folder macontrol can't read says “not scanned” instead of 0 B.
  • A Discard Pile. Stage items, then review them together. The review says how much emptying the Trash will actually free.
  • Keyboard first. Arrows move, Return opens, Esc goes up, ⌘[ ⌘] go back and forward, Space opens Quick Look.

Clean caches and developer leftovers

A vetted catalog of 27 rules: browser caches, Xcode build data, simulator caches, package manager caches (Homebrew, npm, pip, Cargo, Gradle and more), app caches and logs.

  • Safe, Review, Manual. Only Safe items start selected. Manual items, such as iPhone backups and Xcode archives, are never cleaned in bulk.
  • Hands off live data. Anything changed in the last 10 minutes, or belonging to an app that is running, is skipped, and the reason is shown.
  • Rules fail closed. A pattern that reaches outside the folders it is meant for drops its whole rule when the catalog loads.

Remove apps with what they leave behind

Leftovers are matched on evidence: the app's bundle identifier, the containers macOS records as its own, and the background jobs that start it. Each group says why it matched.

  • Cautious by default. Folders that only share the app's name are shown but not selected, and neither is data another app also uses.
  • In the right order. The app is asked to quit, never forced. It goes to the Trash first, and the leftovers you chose follow once it is there.
  • Sort and filter. Sort by name, date added or size, and show all apps, yours or Apple's. New in 0.1.1.

Fast, and right to the byte.

The scan engine reads folders in parallel with getattrlistbulk and backs off in Low Power Mode or when the Mac runs hot. Here it is against two fast command-line scanners.

  • 2.3× fasterthan ncdu, the only other tool that got the test tree exactly right.
  • 75 bytesof memory per item on the test tree. macontrol keeps the whole tree so the map can draw it.
  • No PATH_MAX limitEach folder is opened relative to its parent, so trees nested deeper than macOS's path limit are still measured.

Apple M1, 8 cores, 8 GB, macOS 26.6. Warm cache, hyperfine, 5 timed runs, while another process kept one core busy, so compare the tools with each other rather than with your own Mac. macontrol was measured as mcscan, the app's scan engine as a command-line tool. How it was measured

Built to be boring about your files.

Nothing is deleted permanently in this version. Here is what happens to every item macontrol removes.

  1. You choose itIn Clean only Safe items start selected. Every removal ends in a confirmation that lists exactly what will move.
  2. It is checked againRight before the move, the item is compared with what the scan saw. A file that was replaced, or swapped for a link, stays put.
  3. Protected places are refusedYour home folder and its main folders, Applications, Library and system folders never move.
  4. It goes to the TrashThrough macOS's own Move to Trash. macontrol never empties the Trash: the space comes back when you do.
  5. You can undo itEach batch is written to a journal. History puts it back while it is still in the Trash and its old place is free.

Off limits entirely

Keychains, ~/.ssh, Mail, Messages, photo libraries, privacy data, cloud sync state and /System, contents included.

Cloud needs consent

Items in iCloud Drive or another cloud folder need an extra confirmation, because removing them removes them on every device.

No admin powers

No privileged helper and no password prompt. Root-owned items are marked “Needs admin”, with Reveal in Finder.

One door

Only the Safety module can move files. A test fails if any other code deletes, moves or renames anything.

Coming next.

Designed and planned, not in the current release. Each ships once it has been tested on real Macs.

  • Hardcore mode Planned for 0.2

    An opt-in switch for permanent deletion. It is off every time the app starts, and turning it on asks you to confirm the risk first.

  • Admin removals Planned for 0.2

    Root-owned apps and leftovers, removed after you enter your password, with the safety checks run again as root.

  • Apple app debloat Planned for 0.2

    A checklist of Apple's optional apps, such as GarageBand, iMovie and the iWork apps, with the content they install. Nothing starts selected.

  • Live map Planned for 0.3

    The Disk Map fills in while the scan runs, instead of appearing when it finishes.
