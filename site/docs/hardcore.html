Hardcore mode

Hardcore mode makes removals permanent: they skip the Trash and can't be put back. It is off every time macontrol starts, and it asks before it turns on.

Turn it on

The Hardcore mode checkbox sits at the right end of the toolbar, on every screen. Ticking it opens this warning:

Return and Esc both cancel. The red Turn On Hardcore Mode button has no keyboard shortcut, and there is no menu command or key that turns hardcore mode on.

While it is on, the checkbox turns red and a red banner on every screen says “Hardcore mode is on: removals are permanent.”, with a Turn Off button. Unticking the checkbox, the banner's button or View › Turn Off Hardcore Mode turns it off at once. Quitting macontrol turns it off too: it is never saved.

“Freed X” is measured: macontrol reads the free space before and after the removal. When it is well below the estimate, the result says the rest is held by local snapshots or shared with other files. Every permanent removal still opens its own confirmation, and Return never presses Delete Permanently.

What still goes to the Trash

Some items go to the Trash even in hardcore mode, because deleting them for good is too easy to regret. The confirmation lists them apart, under “Moved to the Trash”, each with its reason:

  • Anything in iCloud Drive or another cloud storage folder. Deleting it there deletes it on every device.
  • Your notes, contacts, calendars and Safari data, and iPhone and iPad backups.

In this preview the confirmation's title still counts these items, although the list shows them apart (T-0085).

What it never deletes

Hardcore mode changes where removals go, not what may be removed. macontrol still never deletes macOS itself, your top-level folders (Documents, Desktop…), Photos libraries, locked files, or anything that changed since the scan. Files you select inside your folders are deleted for good. Every check on the safety model page still runs.

Restore point

The hardcore confirmations in Clean, Uninstall and the Disk Map have an unticked box: Create a restore point first (Time Machine local snapshot, about a minute). It is never automatic. Before you tick it, know what it is:

  • Rolling back returns every file on this Mac to that moment; anything newer is lost. It is done from macOS Recovery › Restore from Time Machine.
  • While it exists, the deleted items still use their space. macOS may remove it on its own. It is not a backup.
  • It covers only the startup disk, and needs at least 1 GB free there. If it can't be made, macontrol asks before it deletes anything.

Debloat's hardcore confirmation does not offer a restore point yet (T-0086).

How a permanent delete works

A file is deleted where it is. A folder first goes to the Trash, like any other removal, and is then erased there, one item at a time, through open folder handles, so a folder swapped for a link halfway through is never followed. If the erase stops halfway, for example because macOS refused one file, nothing is left half deleted in the folder's old place: the result says “Partly deleted. The rest is in the Trash as “name”; empty the Trash to finish.”

In History

Permanent batches have a red icon and say “Deleted permanently”, with no Undo. A batch made after a restore point names the snapshot and how to roll back. Partly deleted batches say so.
