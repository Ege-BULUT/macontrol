macontrol docs

macontrol maps your disk and cleans it up, and everything it removes goes to the Trash first. These pages cover installing it, what it can see, and how each screen works.

0.1 is a preview. It runs on Apple Silicon Macs with macOS 14 or later, it is not notarized yet, and it never deletes anything permanently.
