Questions and answers

Short answers. If a question is about a specific screen, Using macontrol goes deeper.

Does macontrol delete anything permanently?

No. In 0.1 everything goes to the Trash, and macontrol never empties it. History can put a batch back while it is still in the Trash. Permanent deletion is planned for 0.2 as an opt-in hardcore mode.

I removed things, but the free space did not change.

The space comes back when you empty the Trash. Some of it can stay in use even then: clones, snapshots and other hard links can share the same data. The Disk Map review and History say how much emptying the Trash will actually free.

Is it free?

Yes. macontrol is free. There is no account, no subscription and no ads. The source code will be published as open source once licensing is finalized.

Does it send anything anywhere?

No. macontrol has no networking code. It does not check for updates, collect statistics or upload what it scans.

Why is it not notarized?

Notarization needs a paid Apple Developer Program membership, and macontrol does not have one. Releases are signed ad hoc, so macOS asks you to confirm the first launch. The install guide shows the steps.

macOS says the app is damaged and can't be opened.

The app's signature no longer matches its files. That usually means the zip was unpacked with the unzip command, which leaves ._ files inside the app. Delete the app, then unzip the download again by double-clicking it in Finder, or in Terminal:

ditto -x -k ~/Downloads/Macontrol-*.zip ~/Downloads/

If it still happens, download it again and compare its SHA-256 with the one on the install page.

Does it run on Intel Macs?

Not yet. 0.1 is built for Apple Silicon only. Intel and universal builds are on the roadmap.

Why do some folders say “not scanned”?

macOS did not let macontrol read them. Most often that is Mail, Messages, Safari, Cookies and the Trash without Full Disk Access. Their size is unknown, not zero, so macontrol says so instead of showing a smaller number.

Why do I have to allow Full Disk Access again after updating?

macOS ties the permission to the app's signature. Ad hoc signatures change with every build, so each new version counts as a new app.

Why can't it remove GarageBand, iMovie or Pages?

Apple's App Store apps are usually owned by root, so removing them needs an administrator, and 0.1 has no admin powers. It marks them “Needs admin”, with Reveal in Finder. Apps that are part of macOS sit on the sealed system volume and cannot be removed while System Integrity Protection is on. Admin removals and a checklist for Apple's optional apps are planned for 0.2.

Why did Clean skip some items?

It leaves alone anything changed in the last 10 minutes and anything that belongs to an app that is running, because that data may be in use. While an iOS Simulator runs, Clean also skips the caches it cannot inspect. Each skipped item shows the reason.

Where is the source code?

The GitHub repository is private for now. It will be published as open source once licensing is finalized. Build from source covers what you need once you have the code.

How were the speed numbers measured?

With mcscan, the app's scan engine as a command-line tool, against dua and ncdu -t8. hyperfine ran 1 warm-up and 5 timed runs per tool on a warm cache, plus 3 untimed runs to check that each tool reports the same total every time.

  • Test tree: 311,437 items with hard links, clones, deep chains and one unreadable folder. Its true size is 2,368,040,960 bytes allocated. macontrol took 0.68 s and matched it exactly, ncdu took 1.58 s and matched it, dua took 0.60 s and came up 8.4 MB short because it misses hard-linked data.
  • A real projects folder: about 850,000 items. macontrol 2.10 s, dua 1.95 s, ncdu 2.88 s, all three with the same total to the byte.
  • Memory: macontrol keeps the whole tree for the map, about 75 bytes per item on the test tree.

Machine: Apple M1, 8 cores, 8 GB, macOS 26.6, with another process keeping one core busy the whole time. Compare the tools with each other rather than with your own Mac.
