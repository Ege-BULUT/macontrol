Build from source

macontrol is a Swift package with no third-party dependencies. Four commands take you from source to a signed app.

The GitHub repository is private while macontrol is in preview. These steps work once you have the source.

Requirements

Xcode 26 (Swift 6.2) or later. There are no third-party dependencies to install.

Build, test and bundle

git clone https://github.com/Ege-BULUT/macontrol.git
cd macontrol
swift build              # the app and the mcscan tool
swift test               # the test suite
scripts/bundle-app.sh    # release build, wrapped and signed as build/Macontrol.app

Then open build/Macontrol.app from Finder. The tests build their files in temporary folders and never touch your own data or your Trash.

Keep Full Disk Access across rebuilds

By default the bundle script signs ad hoc, and an ad hoc signature changes with every build, so Full Disk Access has to be granted again each time. Set SIGN_IDENTITY to an Apple Development identity to keep it:

SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" scripts/bundle-app.sh

Extras

mcscan prints the allocated size of a folder in bytes, from the same engine the app uses:

swift run -c release mcscan ~/Downloads

The app can render every screen to PNG, in light and dark, with demo data. The screenshots on this site come from it:

build/Macontrol.app/Contents/MacOS/Macontrol --snapshot /tmp/shots

How the pieces fit together, and why, is in docs/ARCHITECTURE.md in the repository.
